# CRC Assets

Cincinnati Recreation Commission maps and briefing material, published with GitHub Pages.

| Page | Link |
|---|---|
| CRC Rec Finder: every CRC property on one map, with rec center site maps and a staff side | https://mreindl118-boop.github.io/CRC/ |
| Rec Finder tour (starts automatically) | https://mreindl118-boop.github.io/CRC/#present |
| Board briefing deck (6 slides) | https://mreindl118-boop.github.io/CRC/deck/ |
| Camp Washington Skatepark | https://mreindl118-boop.github.io/CRC/camp-washington-skatepark/ |

The pages need no account or sign-in and are hidden from search engines (noindex). The Rec Finder can be added to an iPad Home Screen from Safari (Share › Add to Home Screen), and after the first visit it also works offline.

Base map data: Ohio OSIP aerials, OpenStreetMap, City of Cincinnati CAGIS parcels and Census TIGER/Line. Property and amenity data come from CRC records. No Google imagery is used.

Note: this repository is public, so anyone with the link can open the staff side. Keep internal files out of it until a staff sign-in is added.
